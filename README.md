Forecasts each GTA VI trophy's Exophase earn rate a week after launch as five quantiles, with a robust Theil-Sen trend on the logit scale over the last 24 hours of reads and a calibrated spread combining a random-walk term, the fit residual, and slope uncertainty.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
